# Excel Automation Toolkit

Python automation tool designed to copy and consolidate worksheets across multiple Excel workbooks using xlwings.

## Features

- Copy worksheets between Excel files
- Consolidate sheets into a single workbook
- Automatically rename worksheets
- Batch processing support
- Automate repetitive Excel workflows
- Operational reporting support
- Excel-based ETL workflows

## Technologies

- Python
- xlwings
- Excel Automation

## Installation

```bash
pip install xlwings
```

## Usage

Run the script:

```bash
python main.py
```

The script will ask for:

- Destination workbook path
- Source Excel files

## Use Cases

- Operational reporting
- ETL workflows
- Excel consolidation
- Automation of repetitive tasks
- Multi-workbook processing
